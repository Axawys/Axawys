### [PackFoundryWin](https://github.com/Axawys/PackFoundryWin)
Упаковывает Flutter-проекты для Windows в установщик `setup.exe` или портативный `portable.exe`. Умеет сохранять готовый CMD-скрипт, чтобы повторять сборку без приложения.

Изначально я сделал версию под Linux [PackFoundry](https://github.com/Axawys/PackFoundry) (собирает .deb, .rpm, .tar.gz, AppImage), а потом портировал идею на Windows.
